Dashboard Checklist

The first screen a user sees after logging in, providing an at-a-glance overview of the most relevant data, actions, and recent activity.

- [ ] Welcome state — A brief summary of what's happened since the last visit immediately re-orients returning users
  - 💡 A personalised greeting can be a nice touch but isn't ultimately necessary
- [ ] Key metrics — The numbers most relevant to the user's goals, readable without leaving the home screen
  - 💡 Time period context (daily, weekly, monthly) gives numbers meaning at a glance
- [ ] Recent activity — The most recently created or updated items, enabling users to resume work without hunting
- [ ] Needs attention — Time-sensitive items requiring a decision, surfaced here instead of buried in another view
  - 💡 Alert fatigue can happen if this is overdone, so ensure what needs attention is critical and relevant
- [ ] Quick actions — Shortcuts to the most common tasks, accessible without navigating away.
  - 💡 The action users take most frequently after landing is what belongs here
- [ ] Empty state — The state shown when there is nothing to show yet, with a clear first action
  - 💡 A blank dashboard is one of the most common reasons new users churn
- [ ] Layout control (if applicable) — Controls to show, hide, or reorder widgets so the home screen matches how the user works
