# Your Agent Skills Inventory

You have access to a powerful combination of **Local Project Skills**, **Globally Installed Design Skills**, and my **Built-in Antigravity Capabilities**. Here is a breakdown of what you have and how to trigger them.

---

## 1. Project-Specific Skills (Local Workspace)
These are markdown files sitting right in your project folder. You can ask me to read and apply them at any time.

*   **`animartionSkill.md`**
    *   **What it does:** Provides rules and best practices for Awwwards-tier animations (Framer Motion, GSAP, Lenis smooth scrolling, WebGL).
    *   **How to use:** Say *"Animate this component using the rules in `animartionSkill.md`"* or *"Add a scroll effect based on our animation skill."*
*   **`shadcn.md`**
    *   **What it does:** Contains guidelines for correctly generating, modifying, and styling Shadcn UI components.
    *   **How to use:** Say *"Create a new Shadcn form following the `shadcn.md` guidelines."*
*   **`frontendskills.md`**
    *   **What it does:** General frontend architecture and styling rules for this specific project.
    *   **How to use:** Say *"Refactor this page, keeping our `frontendskills.md` in mind."*

## 2. Globally Installed Design Skills (Terminal)
These are tools you recently installed via the terminal (`npx`). They integrate directly with my AI harness (Antigravity/Gemini, Cursor, Claude Code, etc.).

*   **`impeccable` (Design Hook)**
    *   **What it does:** Acts as an automated design linter and audit tool. It catches "design slop" (bad contrast, misaligned layouts, overused templates) before code is finalized.
    *   **How to use:** It runs automatically in the background when generating UI. You can also explicitly say *"Run an Impeccable audit on this page"* or run `/impeccable init` in your terminal.
*   **`web-design-guidelines` (Vercel Agent Skills)**
    *   **What it does:** Injects Vercel's standard, modern web design principles into my context so I build cleaner, more professional interfaces by default.
    *   **How to use:** It triggers automatically for UI tasks, but you can explicitly say *"Follow the web-design-guidelines skill when building this layout."*
